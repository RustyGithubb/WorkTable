# Règles globales (tous projets)

## Qui je suis
- Dorian, technical game designer, vibe codeur amateur.
- Projets : WorkTable (Rust), Roulette Sport (Rust/egui), Weeping Desert (UE5 Blueprint).

## Communication
- Réponds en français, de façon concise. Pas de récapitulatif de ce que tu viens de faire.
- Ne relis pas le code autour si ce n'est pas nécessaire à la tâche.

## Façon de travailler
- Fais UNIQUEMENT ce qui est demandé. Aucune fonctionnalité, refacto ou "amélioration" non demandée.
- Pour une fonctionnalité de plus d'un fichier : propose un plan court et attends ma validation.
- Avance étape par étape, je valide entre chaque étape.
- Si une info manque, pose UNE question plutôt que deviner.

## Git
- Ne jamais faire commit, branche, tag ou push sans mon accord explicite.
- Par défaut, donne-moi les commandes git à lancer moi-même.

## Économie de tokens
- Agents disponibles :
  - `explorateur` : chercher où se trouve quelque chose
  - `build-fixer` : erreurs de compilation Rust
  - `planificateur` : plan d'étapes avant une fonctionnalité multi-fichiers
  - `relecteur` : relire le diff avant de me donner les commandes de commit
  - `changelog` : rédiger l'entrée de CHANGELOG.md
  - `decoupeur` : découper un gros fichier, UNIQUEMENT sur ma demande
- Ne lis jamais `target/`, `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`.
